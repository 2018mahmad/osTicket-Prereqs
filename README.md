## ⚙️ Key Features

- Web-based ticket submission portal  
- Agent and administrator dashboards  
- Ticket categorization, prioritization, and assignment  
- SLA and priority configuration  
- Email notification support  
- Knowledge base and internal notes  
- Full ticket lifecycle tracking (Open → In Progress → Resolved → Closed)

## 🧰 Technologies Used

- Windows 10 Pro (21H2)  
- Microsoft Azure Virtual Machines  
- osTicket  
- Internet Information Services (IIS)  
- PHP  
- MySQL  
- HeidiSQL  
- PHP Manager for IIS  
- VC++ Redistributable  
- IIS URL Rewrite Module  
- Remote Desktop Protocol (RDP)

## 🏗️ Environment Architecture

- Windows 10 virtual machine configured as a web server  
- IIS hosting osTicket web application  
- PHP integrated with IIS  
- MySQL backend database storing ticket data

## 📚 What I Learned

- Installing and configuring IIS on Windows  
- Integrating PHP with IIS  
- Creating and managing MySQL databases  
- Deploying and configuring web applications  
- Understanding ITSM concepts (SLAs, prioritization, escalation)  
- Troubleshooting web server and application issues  
- Writing technical documentation

## 🚧 Challenges & Solutions

**Issue:** PHP extensions not recognized by IIS  
**Solution:** Configured PHP Manager, enabled required extensions, and restarted IIS. Verified handler mappings and reviewed logs to confirm resolution.
